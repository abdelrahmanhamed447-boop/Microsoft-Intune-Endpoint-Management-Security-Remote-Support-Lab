# Microsoft Intune Endpoint Management, Security & Remote Support Lab

## Project Overview

A hands-on Microsoft Intune lab focused on endpoint management, device enrollment, application deployment, configuration and compliance policies, endpoint security, and remote support. The lab demonstrates practical management of Windows and Android devices using Microsoft Intune and Microsoft Entra ID.

---

## Objectives

- Configure Microsoft Intune for endpoint management.
- Enroll and manage Windows devices using Microsoft Intune.
- Enroll and manage Android devices.
- Configure Microsoft Entra ID device registration and management.
- Configure Windows and Android enrollment restrictions.
- Configure device enrollment limits.
- Create and assign Intune Scope Tags.
- Create Windows compliance policies.
- Configure Windows Firewall and Microsoft Defender security requirements.
- Configure device configuration policies.
- Deploy applications to managed devices.
- Configure Microsoft 365 Apps deployment.
- Deploy Win32 applications.
- Configure Android applications through Managed Google Play.
- Configure Android App Protection Policies.
- Configure Conditional Access.
- Configure BitLocker and recovery management.
- Configure Microsoft Intune Remote Help.
- Configure Help Desk Operator role assignments.
- Monitor managed devices and application installation status.

## Lab Implementation

### 1. Device Enrollment & Management

The lab includes Windows and Android device enrollment and management through Microsoft Intune and Microsoft Entra ID.

The implementation covers:

- Windows device enrollment
- Microsoft Entra device registration
- Work or school account connection
- Intune MDM enrollment
- Android device enrollment
- Device synchronization
- Device inventory
- Device management status
- Device compliance status

---

### 2. Enrollment Restrictions

Enrollment restrictions were configured to control which device platforms can be enrolled into Microsoft Intune.

The lab includes:

- Windows enrollment restrictions
- Android enrollment restrictions
- Platform configuration
- Minimum and maximum device limits
- Enrollment restriction assignments

---

### 3. Scope Tags

Intune Scope Tags were configured to organize and control access to Intune resources.

The lab includes:

- Creating Scope Tags
- Assigning Scope Tags to groups
- Managing Intune resources based on administrative scope

Example Scope Tag:

`EGYPTSCOPETAG`

- Policy assignments
